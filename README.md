# Lesson Plans

Grade lesson plans using the `tfi-lesson-plan` Cursor skill.

## Cloud Agents

This repo includes `.cursor/skills/tfi-lesson-plan/` so Cloud Agents get the skill from the project clone.

Invoke with `/tfi-lesson-plan` or ask to create a lesson plan from a textbook PDF/chapter.

## Personal sync

Also keep a copy at `~/.cursor/skills/tfi-lesson-plan` with **Sync Skills for Cloud Agents** enabled (Settings → Agents). Prefer syncing only this skill, not a huge skills dump.
